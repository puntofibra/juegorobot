# LUCAS 5G · Futurmovil

Juego de vuelo neón con Lucas, el robot de Futurmovil.

- Frontend: GitHub Pages (`index.html`, `style.css`, `game.js`, PWA con `manifest.json` y `sw.js`).
- Ranking: Apps Script «juego robot» (`apps-script/Code.gs`) + Google Sheet «juego robot» (hojas *Puntuaciones* y *Config*).
- Premio semanal: se escribe en la hoja *Config*, celda B1.
